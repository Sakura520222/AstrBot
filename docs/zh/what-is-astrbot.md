# 关于 AstrBot

AstrBot 是支持多平台的 AI 聊天助手。它可以连接 QQ、Telegram、飞书、企业微信、Discord、Slack 等消息平台，也提供浏览器聊天界面。

你可以配置模型服务，安装插件，使用知识库、工具调用、Skills、MCP 和定时任务。框架配置、插件及运行日志通过 WebUI 管理。

## 开始使用

1. 按[源码部署](/deploy/astrbot/cli)或 [Docker 部署](/deploy/astrbot/docker)运行 AstrBot。
2. 在[消息平台](/platform/start)中选择需要连接的平台。
3. 按[模型服务](/providers/start)配置模型，或者使用[第三方 Agent 执行器](/providers/agent-runners)。
