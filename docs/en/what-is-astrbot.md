# About AstrBot

AstrBot is an AI chat assistant for messaging platforms including QQ, Telegram, Lark, WeCom, Discord, and Slack. It also provides a browser chat interface.

Configure model providers, install plugins, and use knowledge bases, tool calls, Skills, MCP, and scheduled tasks. The WebUI manages framework configuration, plugins, and logs.

## Get started

1. Run AstrBot using [source deployment](/en/deploy/astrbot/cli) or [Docker](/en/deploy/astrbot/docker).
2. Choose a [messaging platform](/en/platform/start).
3. Configure [model services](/en/providers/start) or a [third-party Agent runner](/en/providers/agent-runners).
