# Feedback and contributions

Report problems and feature requests in [GitHub Issues](https://github.com/Sakura520222/AstrBot/issues).

Include the version, deployment method, reproduction steps, and relevant logs. Remove credentials, account identifiers, and private information before posting logs.

Submit code changes through [pull requests](https://github.com/Sakura520222/AstrBot/pulls). Report plugin issues to the plugin repository and provider or messaging-platform issues to the service maintaining them.
