部署 AstrBot

源码运行需要 Git、uv 和 Python 3.12+。
更新已有实例时，请备份并保留 data/。

阅读源码部署说明 →
源码启动
git clone https://github.com/Sakura520222/AstrBot.git
cd AstrBot
uv sync --locked --inexact
uv run --no-sync main.py
