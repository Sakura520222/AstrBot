# AstrBot v4.30.0-beta.1

版本号对齐上游 4.30.0-beta.1：合并上游 v4.29.4 以来的全部更新（4.30.0-alpha.1、4.30.0-beta.1 及其后 13 个提交），以及本仓库的自有改进。

**本版本为 Beta 测试版，可能存在不稳定或兼容性问题，建议先在测试环境验证。本次涉及对话数据库、Agent 配置和会话设置迁移。升级前请备份数据与配置；回退旧版需同时恢复升级前备份。**

## 内容

### 上游 4.30.0 系列（alpha.1 + beta.1）

- 会话存储迁移为事件溯源方式，减少重复上下文写入与写放大，增量保存消息与工具调用。
- 引入新的 Agent 运行时模型，插件可通过 `ctx.agent.run_turn()` 唤起 Agent turn。
- 子代理重构为具有独立上下文的后台任务，支持追加指令与结果回传，入口移至「配置文件 → AI → 能力 → 子代理」。
- 自定义规则与会话管理统一至「配置文件 → 管理会话配置映射」，支持字段覆盖与批量编辑。
- 新增 Windows AppContainer 本机沙盒，支持工作区隔离、代码执行与联网控制。
- 新增 DeepSeek 语音识别 / 语音合成提供商与 OpenAI Decisions 决策模型。
- 插件 Views 体系：ChatUI 分页工作台与常驻插件视图、消息内交互式 HTML 组件、`metadata.yaml` 统一 `views` 声明。
- ChatUI 支持语音转写为可编辑草稿；推理侧栏改为消息内折叠运行详情；刷新或重连后可恢复正在执行的对话。
- Gemini 4 系列推理强度配置；QQ 官方适配器资料展示、群聊流式回复等修复。
- 性能优化：减少上下文 Token 估算与截断的重复计算，合并会话元数据查询。

### 上游 beta.1 之后的同步提交

- 修复带视图的插件禁用后重新启用时报 "The view's plugin is unavailable" 的问题。 (#11306)
- 补全 KOOK 媒体消息（图片、文件、音频、视频）的解析与组件构造。 (#11115)
- 大模型调用异常时在对话中展示可交互错误卡片，提供详情折叠、重试与配置指引。 (#11259)
- WebUI 聊天页引入动画双侧边栏（导航 Rail 与会话 / 项目抽屉），折叠状态本地持久化。 (#11192)
- 新增全局 `system_language` 配置，内置指令与核心回复支持多语言。 (#11254, #11260)
- 注册 Gemini 4 Neon 思考层级，平台消息高级选项默认折叠展示。 (#11251, #11255)
- 升级 MDI 字体至 7.4.47 并停止跟踪生成的子集字体文件，登录失败延迟测试 mock 等 CI 与测试优化。

### 本仓库自有更新（自 v4.29.4）

- 恢复更新检查与刷新网站文档；官网与文档站统一构建并部署至 astrbot.pyabunny.com。
- 新增生产环境 HTTPS 部署文档；Windows 符号链接权限相关测试兼容处理。
- 上游原始发布说明归档于 [changelogs/upstream/v4.30.0-beta.1.md](upstream/v4.30.0-beta.1.md)。
