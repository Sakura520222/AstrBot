# PyaBot v4.30.0-beta.2

包含 [v4.30.0-beta.1](v4.30.0-beta.1.md) 的全部内容，以及项目更名为 PyaBot 带来的更新与修复，没有新增上游提交。

**本版本为 Beta 测试版，可能存在不稳定或兼容性问题，建议先在测试环境验证。升级前请备份数据与配置；回退旧版需同时恢复升级前备份。**

## 内容

### 项目更名为 PyaBot

- 品牌、发行包、CLI 主命令（`pyabot`）、WebUI、官网与文档统一为 PyaBot，域名迁移至 pyabot.pyabunny.com。
- 核心与 WebUI 更新改用本仓库的 Release：版本查询使用 <https://pyabot.pyabunny.com/releases.json>，发布包命名为 `PyaBot-v<版本>-core.zip` 与 `PyaBot-v<版本>-dashboard.zip`。
- 保持 AstrBot 插件兼容：内部保留 `astrbot` 包路径、`astrbot` 命令别名与 `ASTRBOT_*` 环境变量，新增 `pyabot` 导入门面与 `PYABOT_*` 环境变量；`pyabot.api` 与 `astrbot.api` 共用同一套模块和注册表。

### 修复

- 修复源码全新安装时 WebUI 无法使用的问题：v4.30.0-beta.1 发布后项目更名为 PyaBot，启动时改为下载 `PyaBot-` 命名的 WebUI 包，而该版本的 Release 只有 `AstrBot-` 命名的包，下载返回 404，核心照常启动但 WebUI 显示「文件缺失」。本版本使版本号、站点更新清单和两个 ZIP 文件名保持一致。
- SSYCloud（盛水渊）模型服务默认的 `X-Title` 请求头改为 PyaBot。

## 升级

从 v4.30.0-beta.1 及更早版本升级时，旧版本在 WebUI 内更新会查找 `AstrBot-` 命名的发布包，无法直接更新到本版本。请停止实例并备份 `data/`，用 `PyaBot-v4.30.0-beta.2-core.zip` 中的文件替换程序文件，保留原有的 `data/`，然后重新启动；启动时会自动下载本版本的 WebUI 并更新 `data/dist`。
