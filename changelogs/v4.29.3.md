# AstrBot 个人 Fork v4.29.3

Sakura520222 独立维护的首个 AstrBot Fork 正式版，基于上游 4.29.3，暂时保留 AstrBot 名称和标识。

## 首版内容

- 版本号对齐上游 4.29.3，保留正常插件版本检查和数据兼容规则。
- 核心更新、WebUI 下载、反馈和代码入口切至 `Sakura520222/AstrBot`。
- 重整 GitHub Actions，自动构建核心/WebUI ZIP、Python wheel/sdist、SHA256 校验文件和 GHCR 镜像，发布中文 Release。
- 建立中文官网与文档站，通过 Cloudflare Pages 自动部署并接入 pyabunny.com 子域名。
- 为 WebUI 增加发行来源标记，避免同版本官方资源被误认为个人 Fork 资源。
- 限定 Python 分发包内容，排除运行数据、虚拟环境和 node_modules。
- 重写中文 README 和 AGENTS.md，说明开发、发布、插件兼容及运行数据保留约定。
- 保留 AstrBot 核心能力、公共插件生态、上游历史、署名和 AGPL-3.0-or-later 许可。

## 下载和部署

- `AstrBot-v4.29.3-core.zip`：核心源码包。
- `AstrBot-v4.29.3-dashboard.zip`：对应 WebUI，解压后为 `dist/`。
- `.whl` / `.tar.gz`：包含 WebUI 的 Python 分发包，不向上游 PyPI 自动发布。
- `SHA256SUMS`：下载资产校验和。
- 镜像：`ghcr.io/sakura520222/astrbot:4.29.3`，同时更新 `latest`。

已有实例先备份并保留 `data/`。框架配置、插件及其配置、数据库和插件数据不属于源码发布包。

## 版本兼容

项目版本继续使用 4.29.3，与上游基线一致，不重置为独立的 1.x 序列。Fork 的代码归属、发布、下载和站点保持独立。

感谢 AstrBot 原作者与所有贡献者。本版本是个人 Fork 发行，不是 AstrBotDevs 官方版本。
