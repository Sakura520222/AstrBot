# AstrBot v4.29.4

版本号对齐上游 4.29.4，合并上游 v4.29.3 以来全部 48 个提交。

## 内容

- 合并上游 v4.29.3 → v4.29.4 更新，主要包括：
  - Agent：内置 Agent 运行时会话化重构，新增 Profile 级子代理管理与 OpenAI Decisions 决策模型。
  - 沙盒：新增 Windows AppContainer 原生沙盒运行环境。
  - 消息按钮：新增跨平台可移植按钮组件，QQ 按钮回复保留媒体内容。
  - 交付同步：新增 Project 交付同步与项目同步测试。
  - 稳定性：修复控制台背压阻塞事件循环、Web 搜索密钥级失败重试、插件失败日志归属、`text_chat` 重试误判等问题。
  - WebUI：支持可折叠配置分组、插件桥接主题色、控制台日志时间戳增加日期，优化多处布局与滚动行为。
  - 依赖：新增 Windows 平台 `pywin32`，更新若干构建依赖。
- 源码、问题反馈、核心更新和 WebUI 下载使用 Sakura520222/AstrBot。
- GitHub Actions 构建核心与 WebUI ZIP、Python wheel/sdist、校验文件和 GHCR 镜像。
- 官网与文档统一使用 astrbot.pyabunny.com。
- 上游原始发布说明归档于 [changelogs/upstream/v4.29.4.md](upstream/v4.29.4.md)。
